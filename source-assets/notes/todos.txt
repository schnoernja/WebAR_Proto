Während der aktiven Entwicklungsphase wird auf dem externen Server ausschließlich
der Produktionsstand betrieben. Das Git-Repository und die Entwicklungsdateien werden
nicht als Arbeitskopie auf dem Server verwendet.

Nach Abschluss des Projekts wird zusätzlich ein versioniertes Abschlussarchiv des
relevanten Projektstands erstellt und getrennt vom öffentlich erreichbaren Webroot
auf dem Server abgelegt. Dieses Archiv dient ausschließlich als Sicherung und Abgabe,
nicht als öffentlich ausgelieferte Anwendung.

Das Abschlussarchiv muss:

- einem eindeutigen Git-Tag oder Commit entsprechen,
- den relevanten Quellcode, die Build-Konfiguration und Dokumentation enthalten,
- alle für einen erneuten Build erforderlichen Dateien enthalten,
- keine privaten Schlüssel, Zugangsdaten oder lokalen Geheimnisse enthalten,
- eine README mit Build-, Start- und Wiederherstellungsanleitung enthalten,
- eine Liste der ausgelieferten Runtime-Dateien und Prüfsummen enthalten.

Das Archiv darf nicht innerhalb des öffentlich erreichbaren Webroots liegen.
